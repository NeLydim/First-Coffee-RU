# NelyFonts

Плагин для **exteraGram** и **AyuGram**, который заменяет шрифт во всём приложении на ваш: в сообщениях, списке чатов, меню, заголовках и настройках. Смена шрифта происходит на лету, без перезапуска.

В репозитории также лежит шрифт **First Coffee RU** (`First_Coffee_RU.ttf`, `First_Coffee_RU.otf`) — его можно поставить одной кнопкой прямо из плагина.

## Установка

1. Скачайте [`NelyFonts.plugin`](NelyFonts.plugin).
2. Отправьте файл в «Избранное» в exteraGram/AyuGram и нажмите на него.
3. Подтвердите установку и откройте настройки плагина.

## Как выбрать шрифт

| Способ | Что делать |
|---|---|
| **Выбрать файлы шрифта** | Откроется системный выбор файлов. Можно отметить сразу несколько (Regular, Bold, Italic…) или ZIP-архив с семейством — начертания распределятся автоматически. |
| **Шрифты из загрузок Telegram** | Отправьте `.ttf`/`.otf`/`.zip` в «Избранное», нажмите на файл, чтобы он скачался, — и он появится в этом списке. |
| **Скачать по ссылке** | Вставьте прямую ссылку. Ссылки на GitHub (`/blob/`), Google Drive и Dropbox преобразуются в прямые автоматически. |
| **Установить First Coffee RU** | Скачивает шрифт из этого репозитория. |
| **Начертания семейства** | Отдельный файл для каждого начертания: обычного, среднего, жирного, курсива и т. д. |

Поддерживаются **TTF, OTF, TTC** и **ZIP**. WOFF/WOFF2 (веб-шрифты) Android не умеет — плагин об этом скажет.

## Возможности

- **Семейства начертаний.** Настоящие Bold/Medium/Italic, если они есть. Остальные начертания синтезируются: жирный — утолщением, курсив — наклоном.
- **Вариативные шрифты.** Веса и наклон берутся из осей `wght`/`ital`/`slnt` — без «искусственного» жирного.
- **Проверка файла до применения.** Битый, недокачанный или «не тот» файл не заменит рабочий шрифт.
- **Сведения о шрифте:** семейство, формат, число глифов, наличие кириллицы, латиницы и цифр.
- **Настройки:** «средний вес как жирный», сохранение моноширинного шрифта (код) и шрифта с засечками.
- **Шрифт везде, а не местами:** сообщения, список чатов, меню, заголовки, профиль, закреплённые сообщения, плашки и настройки.
- **Без нагрузки на отрисовку.** Шрифт подменяется в момент создания гарнитур и текстовых элементов. Хуков на `draw`/`Canvas` нет.
- **Диагностика:** инспектор шрифта, проверка текущего экрана, копирование отчёта для поддержки.
- **Перезапуск приложения** одной кнопкой, если нужно обновить уже открытые чаты.

## Как это работает

- **Кеш шрифтов Telegram.** Гарнитуры кладутся прямо в `AndroidUtilities.typefaceCache` и `mediumTypeface`. Их читают `regular()`/`bold()`/`getTypeface()`, даже когда Android встроил эти короткие методы в место вызова и хук их не видит. Если кеш очищается (например, переключателем «Системный шрифт»), плагин сразу заполняет его снова.
- **Создание элементов.** `TextView`, `SimpleTextView`, анимированный текст и `TextPaint` получают шрифт прямо в конструкторе. Если в какой-то сборке кеш недоступен, плагин запоминает штатные гарнитуры и подменяет их здесь.
- **Уже созданное.** Статические `Paint` в `Theme` и других классах, а также видимые элементы экрана, бокового меню и шапок обновляются одним проходом. При выключении всё возвращается обратно.
- **Классы Java.** `find_class()` в exteraGram возвращает прокси Chaquopy без `getDeclaredMethod`, поэтому классы берутся через `Class.forName`, а методы перехватываются по одному.
- **Импорт.** Файл копируется через настоящий Java `byte[]` (`jarray`): Python `bytearray` Chaquopy передаёт в Java копией. Шрифт сохраняется под новым именем и подставляется через `rename`, потому что Android держит файл шрифта в `mmap`.
- **Переустановка.** Хуки предыдущей копии плагина сверяют метку экземпляра и ничего не делают.

## Для разработчиков

Офлайн-тесты (заглушки SDK, разбор шрифтов, импорт, хуки):

```bash
python -m unittest discover -s tests -v
```

Тестовые шрифты в `tests/fixtures/` сгенерированы fontTools и весят около 1–2 КБ.

Имена папок (`nelyfonts`), ключи настроек и поля `meta.json` хранятся на устройстве пользователя. Их нельзя переименовывать, иначе пропадут импортированный шрифт и настройки.
